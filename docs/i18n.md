# Internationalisation (i18n)

## Configuration

Planoka utilise **next-intl v4** pour l'internationalisation. La configuration se trouve dans `i18n.ts`.

### Locales supportees

| Code | Langue   | Defaut |
| ---- | -------- | ------ |
| `fr` | Francais | Oui    |
| `en` | Anglais  | Non    |

### Fonctionnement

1. Le middleware (`proxy.ts`) utilise `next-intl/middleware` avec `localePrefix: "always"`. Chaque URL est systematiquement prefixee par la locale : `/fr/plans`, `/en/plans`.
2. Le fichier `i18n.ts` charge dynamiquement le bon fichier de traduction (`messages/fr.json` ou `messages/en.json`).
3. Le prefixe locale est extrait du pathname via `getLocaleFromPathname()` dans `lib/clerk-paths.ts`.

## Fichiers de traduction

Les traductions se trouvent dans `messages/` :

```
messages/
├── fr.json     # Francais (23 Ko, traduction de reference)
└── en.json     # Anglais  (20 Ko)
```

### Structure des cles

Les traductions sont organisees par namespace :

```json

  "common": {
    "appName": "Planoka",

```

## Utilisation dans les composants

### Composants Client ("use client")

```tsx
import { useTranslations } from "next-intl";

function MyComponent() {
  const t = useTranslations("plans");
  return <h1>{t("title")}</h1>;
}
```

### Acces a la locale

```tsx
import { useLocale } from "next-intl";

function MyComponent() {
  const locale = useLocale(); // "fr" ou "en"
}
```

## Ajouter une nouvelle cle de traduction

1. Ajouter la cle dans `messages/fr.json` (fichier de reference).
2. Ajouter la traduction equivalente dans `messages/en.json`.
3. Utiliser `t("namespace.key")` dans le composant.

## Ajouter une nouvelle langue

1. Ajouter le code locale dans `i18n.ts` :
   ```typescript
   export const locales = ["fr", "en", "es"] as const;
   ```
2. Creer le fichier `messages/es.json` avec toutes les cles traduites.
3. Le middleware detectera automatiquement la nouvelle locale.

## Bascule de langue

Le composant `components/common/LanguageToggle.tsx` permet a l'utilisateur de changer de langue. Il utilise `useRouter` de `next/navigation` pour naviguer vers la meme page dans l'autre locale.
